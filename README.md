### About

后端为主，偶尔写前端。日常在 Spring 生态和微服务里打转，最近也在用 AI 辅助拆需求、写代码和做审查。

更在意系统能不能稳定跑、边界清不清楚、数据是否一致，而不是 commit 数量。

- 当前在做：基于 Spring Cloud Gateway 的 JWT 认证链路梳理与优化
- 近期实践：Docker / Compose 编排、Redis Sentinel、Nacos 集群相关配置与排障
- 工具偏好：Codex 辅助开发（需求拆解 → 生成 → 人工审查 → 接口验证）

### Projects

**[HAOVP](https://git.uo.do/Toyas/HAOVP)** — 在线视频平台  
Demo: [nyzxi.com](https://nyzxi.com)

独立完成前后端与部署。Spring Cloud 微服务 + Vue 3，MinIO 存视频，RocketMQ 处理部分异步，双 Token + Redis 做认证与权限。

主要点：
- Access / Refresh Token 刷新与失效控制
- 点赞、评论、完播等行为驱动的简单推荐
- Docker Compose 编排（MySQL 主从、Redis Sentinel、Nacos、MinIO、Sentinel）
- 全程用 Codex 辅助，自己负责架构、审查和验收

**教育数据中台**（2024.09 – 2025.08）

校内多业务系统数据接入与共享。接入约 20 个核心数据源，维护 1300+ 同步任务与标准化 API，处理过亿级存量数据清洗与入库。负责权限、监控、备份和日常排障。

**云启·安全训赛平台**（2023.06 – 2024.08）

高校网络安全教学与竞赛平台。做过 AWD、红蓝对抗等模式的任务配置、计分、资源分配和 WebSocket 实时推送。

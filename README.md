### 💡 The Architect's Mindset

比起沉迷于刷 Commit 数量，我更倾向于将精力投入在**系统架构设计、底层逻辑重构与前沿开源技术的吸收**上。我相信优秀的工程师不仅要会写代码，更要懂得如何借助社区力量与 AI 工具，站在巨人的肩膀上解决复杂的工程挑战。

- 🔭 **Current Deep Dive:** 持续深化微服务安全架构，重构并优化基于 Spring Cloud Gateway 的 JWT 核心认证过滤器。
- ☁️ **Cloud & AI Practices:** 积极构建智能化开发工作流，深入使用 Google Cloud 与 Google AI Studio 进行环境配置，利用 Secret Manager 管理核心凭证，并正推进项目向 Gemini 3.1 Flash Lite 模型的全面迁移。
- ⚡ **Engineering Highlight:** 独立完成 **HAOVP 高可用在线视频平台** 的全栈开发与容器化部署，成功落地千万级数据的异步互动数据一致性控制与微服务限流降级。
- 🌟 **Open Source Curator:** 习惯于穿梭在 GitHub 中发掘和剖析优秀的开源项目，保持对前沿技术的极高敏锐度。
